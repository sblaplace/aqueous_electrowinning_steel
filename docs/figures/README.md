# Figures

Diagrams, plots, and images for the research report and presentations.

## Generated Figures

All figures are regenerated by the driver scripts in `models/`.

### Electrochemistry (`python -m models.run_electrochemistry`)
| File | Description |
|------|-------------|
| `pourbaix_fe_h2o.png` | Fe–H₂O potential–pH diagram with water stability window and HER penalty |
| `polarization_curves.png` | Fe and HER partial-current Tafel branches; current efficiency vs. current density |
| `current_efficiency_map.png` | CE contour map over (j, i₀,HER) and resulting specific-energy penalty |

### Techno-economics (`python -m models.run_technoeconomic`, `run_scenarios`)
| File | Description |
|------|-------------|
| `voltage_breakdown.png` | Cell voltage decomposition |
| `opex_breakdown.png` | OPEX cost structure |
| `cost_comparison.png` | Route-by-route cost comparison |
| `energy_vs_cost.png` | Specific energy vs. levelized cost |
| `sensitivity_analysis.png` | One-at-a-time LCOFe sensitivity |
| `scenario_comparison.png`, `scenario_radar.png` | Four-scenario comparison |

### Phase I EIS (`python -m models.run_eis`)
| File | Description |
|------|-------------|
| `eis_nyquist.png` | Synthetic cathode spectrum and Randles ± Warburg equivalent-circuit fits |
| `eis_bode.png` | Bode |Z| and phase with Randles + Warburg fit |

### Phase II Hull Cell & Gravimetry (`python -m models.run_hull_cell`)
| File | Description |
|------|-------------|
| `hull_cell_current_distribution.png` | Variable-gap primary-current screen over an angled 10 × 5 cm panel; schematic and local current-density map |
| `gravimetric_faradaic_efficiency.png` | Synthetic galvanostatic trace and blank-corrected apparent gravimetric Fe Faradaic-efficiency mass balance |

The Phase II figures are modelling/data-analysis outputs, not images of a
physical deposit.  The angled-panel map is normalized to applied current but
is not a calibrated current-distribution measurement; see `models/README.md`
for excluded effects and `experiments/data/README.md` for the mass-balance QA
procedure.
